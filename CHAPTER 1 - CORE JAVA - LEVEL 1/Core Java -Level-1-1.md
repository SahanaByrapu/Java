**(1)What is Java?**
* Java is high-level, class-based, object oriented programming language 
* designed to have fewer dependencies as possible.
* widely used in developing applications for mobile, web and desktop platforms.


**(2)What are features of Java?**
1. Platform independence
2. Object Orientation
3. Security
4. Robustness
5. Simplicity
6. Multithreading
7. Garbage Collection

**(3)What is JVM and why is it important?**
JVM is part JRE that executes byte code. It is important as it provides platform-independent way of executing Java code.

**(4)What is the difference between JDK, JRE and JVM?**
**JDK** full software development kit to develop Java applications.
**JRE** subset of JDK that provides environment to run Java programs
**JVM** subset of JRE that is to execute Java byte code.

**(5)What is the use of public static void main(String[] args) method?**
This method is the entry point to Java application. It is the method called by JVM to run the program.

**(6)Explain the concept of Object-Oriented Programming in Java**
* Programming paradigm based on the concept of Objects
* Contains data inform of fields (attributes) and code in the form of procedures(methods).
* Follows OOPs principles - Encapsulation,  Polymorphism, Inheritence and Abstraction.
